# 小金豆糕点PC端电商平台开发计划

## 1. 技术栈选择
- **前端框架**：纯HTML5 + CSS3 + JavaScript (ES6+)
- **样式预处理**：使用CSS变量管理主题色
- **UI组件库**：无（自定义开发，保持轻量）
- **图片格式**：WebP（优先）+ PNG（备用）
- **静态数据管理**：集中的JSON文件 + 部分硬编码

## 3. 页面开发顺序
1. **基础结构搭建**：创建HTML骨架、CSS重置和全局样式
2. **全局组件开发**：导航栏、搜索框、页脚
3. **首页开发**：Banner轮播、金刚区、特色栏目
4. **分类页面开发**：全部分类页、各子分类页
5. **商品详情页开发**：主图轮播、规格选择、详情图文、评价展示
6. **辅助页面开发**：活动页、搜索结果页、关于我们、配送须知
7. **交互功能实现**：筛选排序、规格切换、收藏按钮、CTA跳转

## 4. 核心功能实现方案
### 4.1 搜索功能
- 搜索框输入关键词后跳转至`search-results.html?keyword=xxx`
- 前端根据URL参数展示对应预设商品列表
- 热门搜索词静态展示在搜索框下方

### 4.2 Banner轮播
- 使用原生JavaScript实现
- 支持左右箭头切换和指示器点击
- 自动播放功能
- 点击跳转至对应活动页

### 4.3 商品规格选择
- 点击不同规格选项，JavaScript动态更新价格和说明
- 使用CSS类切换选中状态

### 4.4 底部操作栏
- 联系客服：触发电话拨打或打开聊天工具
- 收藏：切换图标状态（无持久化）
- 立即咨询：平滑滚动至联系方式区域

## 5. 设计风格实现
- **色调**：主色调使用暖色调（#FFE6CC），辅助色金色（#D4AF37），文字色深咖（#333333）
- **字体**：中文使用思源黑体，西文使用Helvetica
- **布局**：采用响应式设计，最小支持1280px宽度
- **动画效果**：轮播过渡、按钮hover效果、平滑滚动

## 6. 性能优化
- 图片懒加载
- 压缩CSS和JavaScript
- 使用WebP格式图片
- 合理使用CSS变量和选择器

## 7. 测试计划
